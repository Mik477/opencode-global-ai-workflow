# Focused Plan Execution

**REQUIRED GOVERNING SKILL:** Use `focused-delivery`. An approved plan does not acquire new approval or review gates in a new session.

Read the goal contract and plan, verify the intended workspace, and resume the first incomplete vertical slice. Raise only a material contradiction that prevents safe execution; resolve routine gaps from repository evidence and reversible judgment.

Maintain a reasonably scaled execution tree, not one task per plan checkbox. Execute autonomously through the approved slices with proportionate verification, one review per slice, one fix wave, one scoped re-review, relevant provenance, and user-owned browser testing.

Do not ask the user to choose subagent-driven versus inline execution, require checkpoint approvals, invoke an integration menu, commit, or start a final review. Stop only for a material decision outside the contract or a residual blocker after the allowed re-review.
