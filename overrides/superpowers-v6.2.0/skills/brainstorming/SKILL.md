# Focused Brainstorming

**REQUIRED GOVERNING SKILL:** Invoke `focused-delivery` and follow its goal contract and approval rules.

Inspect relevant project context first. Inventory foreseeable material questions and ask independent questions in one concise batch. Ask a later question only when an answer reveals a genuinely new dependency.

When a material choice exists, present two or three approaches with trade-offs and a recommendation. Then present one cohesive design and comprehensive implementation plan with the focused-delivery contract. Request one combined approval.

Do not require section-by-section approval, a second written-spec review, an execution-mode choice, or a commit. Trivial reversible work does not use this skill. Do not offer or launch a visual companion unless the user explicitly requests agent-run visual assistance.

After approval, save useful durable records, self-review them, and start implementation without another gate.
